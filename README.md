# Superstore Data Analysis

## 📌 Project Overview

This project focuses on analyzing the Superstore dataset to discover useful business insights and understand sales and profit performance.

The project includes data cleaning, exploratory data analysis (EDA), statistical analysis, KPI calculation, and data visualization.

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 🧹 Data Cleaning

The dataset was prepared by handling:

- Missing values
- Duplicate records
- Outliers
- Inconsistent data
- Data formatting issues

## 📊 Analysis

The analysis focuses on:

- Sales performance
- Profit performance
- Profit Margin
- Shipping Duration
- Sales Performance Categories
- Key Performance Indicators (KPIs)
- Exploratory Data Analysis (EDA)

## 📈 Visualizations

The project contains multiple visualizations to help understand:

- Sales trends
- Profit performance
- Category and regional performance
- Customer and product-related insights
- Relationships between different variables

## 📂 Files

- `Mini_Project_1_Superstore_Analysis_Execution...` — Jupyter Notebook containing the complete analysis.
- `Sample - Superstore 2019.xls` — Original dataset used in the project.

## 🎯 Objective

The main objective of this project is to practice the complete data analysis workflow using Python, from data preparation and cleaning to analysis, visualization, and extracting meaningful insights.
